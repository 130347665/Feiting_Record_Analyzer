# 🏁 飛艇記錄查詢器

這是一款使用 Rust + egui + reqwest 打造的桌面 GUI 工具，專門用於查詢與分析各類飛艇／賽車遊戲的歷史開獎紀錄。支援 Cookie 登入、複合連續模式匹配、繁體中文介面顯示。

---

## 🔧 功能特色

- 🎮 支援多種遊戲類型：
  - SG飛艇
  - 幸運飛艇
  - 急速飛艇
  - 急速賽車
- 🔐 自訂輸入 Cookie 進行授權
- 📥 一鍵抓取 `https://www.15678.vip` 開獎資料
- 🔍 支援複合連續模式查詢（如：1單單23雙雙，可同時指定多個位置與多期模式）
- 🕒 自動轉換為北京時間（支援毫秒顯示）
- 🖼️ 繁體中文介面，使用微軟正黑體字型顯示
- 🛡️ 完善的錯誤提示與格式檢查

## 📦 建置方式

### 1. 安裝前置工具

請確認你已安裝：
- Rust 工具鏈（推薦使用 [https://rustup.rs](https://rustup.rs) 安裝）
- Cargo 套件管理工具（隨 Rust 安裝）
- Windows 字型路徑：`C:/Windows/Fonts/msyh.ttc`（微軟正黑體）

### 2. Clone 並建置專案

```bash
git clone https://your-repo-url
cd your-project-folder
cargo build --release
```

### 3. 執行應用程式

```bash
cargo run --release
```

或直接執行生成的 .exe 檔案。

## 🖥️ 操作說明

1. 啟動後，請先輸入你的登入 Cookie。
2. 選擇一個遊戲（可即時切換）。
3. 點擊「📥 獲取數據」。
4. 若要查找連續模式，可輸入複合規則（如：1單單23雙雙，數字代表位置，後面跟多期模式）。
5. 滾動查看所有匹配結果，包含期數、開獎結果與每個位置的「大/小/單/雙」特徵。
6. 若模式格式錯誤，會有紅字提示。

### 💡連續模式格式說明
- 格式範例：1單單23雙雙
- 1單單：第1位連續兩期分別為「單」
- 23雙雙：第2或第3位連續兩期分別為「雙」
- 支援模式：單、雙、大、小（大表示≥6，小表示<6）
- 可組合多個位置與多期模式
