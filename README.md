🏁 飛艇記錄查詢器
一款使用 Rust + egui + reqwest 製作的桌面 GUI 工具，能查詢多種飛艇/賽車遊戲的歷史開獎紀錄，支援連續期數模式匹配（例如：「單單雙」、「大小大」等）。

🔧 功能特色
✅ 支援以下遊戲：

SG飛艇

幸運飛艇

急速飛艇

急速賽車

🔑 支援自訂輸入 Cookie 以存取資料

📥 一鍵取得遊戲歷史開獎資料（從 https://www.15678.vip ）

🔍 自訂連續期數條件（如：單單雙）查找符合的歷史期數

🕒 自動顯示開獎時間（轉為北京時區並支援毫秒）

🖼️ 繁體中文 GUI，並使用微軟正黑體顯示

📋 顯示全部開獎資料或條件篩選後的匹配結果

🖥️ 操作說明
啟動應用後，請於畫面左上輸入您的 登入 Cookie。

選擇一個遊戲（預設為 SG飛艇）。

點擊「📥 獲取數據」。

若要查找連續模式，可輸入模式（例如：單雙單、大小大）。

滾動查看所有匹配結果，包含期數、開獎結果與首號條件。

📌 注意事項
網頁來源為 https://www.15678.vip，需具備有效 Cookie 權限才能正常抓取數據。
